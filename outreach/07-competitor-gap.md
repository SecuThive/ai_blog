### 4. 타 블로그 "학습 로드맵/추천 자료" 글에 인용되기

44BITS는 moons08 로드맵 글 **한 페이지에서만 dofollow 3개**를 얻었다.
인용되는 건 언제나 **"그 주제의 결정판 한 편"**이지 얕은 글 묶음이 아니다.
→ 액션은 **아웃리치가 아니라 콘텐츠 심화**다. 상위 3개 트래픽 글을 정확한 명령어 출력·버전별 차이·오답 케이스까지 담은 표준 레퍼런스로 확장한다. (`BACKLINK_REPORT.md` 액션 8번과 동일 맥락)

### 5. GitHub 큐레이션 북마크 레포 — 별도 액션 없음

유지자가 RSS를 읽고 담는 구조라 **1·2번 성공의 후행 지표**로 삼는다. 직접 제출하지 않는다.

### 6. 디스콰이엇 제품 등록 — ⚠️ 기존 판단 뒤집힘

`05-directory-prs-ready.md`는 디스콰이엇을 *"제품 등록 서비스, 미디어 부적합"*으로 **제외**했었다.
그런데 이번 조사에서 **요즘IT가 실제로 제품으로 등록돼 있고 아웃바운드 링크가 확인**됐다 → https://disquiet.io/product/요즘it
**제외 근거가 무너졌다.** 미디어도 "제품"으로 등록 가능하며 실명 엔지니어가 필요 없다. → **재검토 대상으로 복귀.**

### 7. Medium / velog 정식 미러 — 조건부

44BITS가 medium.com/44bits를 운영한다. 조직 계정 가능, 개인 페르소나 불필요.
⚠️ **canonical 태그 없이 전문을 복제하면 자기잠식(self-cannibalization)이다.** 요약본 + "원문 보기" 링크 형태만 허용.

## (c) Nodelog에게 금지·불가한 채널 (명시적으로 배제)

| 채널 | 배제 사유 |
| --- | --- |
| **awesome-devblog `db.yml`** | 저장소 규칙이 **"실명만"**. 공개 저자 페르소나가 없는 Nodelog는 규칙 위반 → 반드시 `db_community.yml`로만 간다 |
| **인프런 강사/멘토 프로필** | 실명 강사 등록 + 실제 강의 제작이 전제. 현 구조로 불가 |

| **언론 인터뷰(ZDNet·전자신문급)** | 요즘IT는 위시켓 법인 배경과 정식 런칭 이벤트가 있었다. **AI 보조 미디어 정체성이 공개될 경우 부정적 기사 리스크** → 비권장 |
| **오리지널 리서치 링크베이트** | 1차 측정을 실제로 하지 않는다면 **부정확한 데이터 유포**가 된다. 실측할 각오가 있을 때만 (액션 8번) |
| **OKKY·커리어리 게시글 링크** | 포럼 스팸 금지 원칙에 저촉 위험. 경쟁사가 이 경로를 쓴다는 증거도 **확인되지 않음** → 비권장 |

## 이번 조사가 만든 기술 액션

**피드 경로 별칭 부재** — 실측 결과 `/rss`만 200이고 `/rss.xml` `/feed` `/feed.xml` `/atom.xml`은 **전부 404**였다.
디렉토리·애그리게이터·RSS 리더 상당수가 `/rss.xml`이나 `/feed`를 관례적으로 먼저 조회하므로, 별칭이 없으면 **제출처에서 "피드 없음"으로 판정돼 등재 자체가 막힐 수 있다.**

→ `next.config.ts`에 4개 경로 → `/rss` 308 영구 리다이렉트를 **추가했다** (typecheck 통과).
→ ⚠️ **아직 배포 전이라 프로덕션은 여전히 404다.** 디렉토리 제출 **이전에** 배포되어야 한다.
