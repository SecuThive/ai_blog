# outreach/

Nodelog(https://www.thivelab.com) 링크 빌딩 아웃리치 **초안 보관소**.

## 규칙

- **이 폴더의 메일·DM은 발송하지 않는다.** 사람이 검토·수정한 뒤 직접 보낸다.
- 대상은 1건씩 개별 작성한다. 같은 본문을 여러 곳에 복사 발송하지 않는다.
- 유료 링크 구매, PBN, 자동 댓글·포럼 스팸, 대량 자동 제출 금지.
- 상대 사이트에 실제로 도움이 되는 제안만 보낸다. 도움이 안 되면 보내지 않는다.

## 파일

| 파일 | 용도 |
| --- | --- |
| `01-unlinked-mention.md` | 언급 조사 전량 기록·감시 체계 (**2026-07-20 결론: 언급 0건**) |
| `02-broken-link.md` | 리소스 페이지의 깨진 링크를 우리 가이드로 대체 제안 (실측 8건) |
| `03-guest-post.md` | 게스트 기고·커뮤니티 기여 제안 |
| `04-directory-submission.md` | 디렉토리·인덱스 등록 시 사용할 표준 소개 문구 |
| `05-directory-prs-ready.md` | PR·제출 실행 준비 완료본 (승인 대기) |
| `06-directory-email.md` | 디렉토리 등록 요청 메일 초안 |
| `07-competitor-gap.md` | 경쟁사 링크 채널 비교·격차 분석 |

> 전체 현황과 등록 내역은 저장소 루트 **`BACKLINK_REPORT.md`** 에 있다.

## 발송 전 체크리스트

- [ ] 상대 페이지를 실제로 읽었고, 본문에 그 내용을 구체적으로 인용했는가
- [ ] 제안한 우리 URL이 200으로 열리고 상대 문맥에 정말 맞는가
- [ ] 깨진 링크 주장 시 HTTP 상태를 직접 확인했는가
- [ ] 링크를 "요구"하지 않고 판단을 상대에게 맡겼는가
- [ ] 발신자 신원(운영 주체·연락처)을 숨기지 않았는가
