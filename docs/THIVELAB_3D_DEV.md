# THIVELAB 3D DEV 시안

2026-10-10 기준 DEV 서버(`thivelab-dev`, 3104)에서 제작한 시안이다. 같은 날 검증된 일부 파일을 새 운영 릴리스로 반영했다. Cloudflare·Caddy·DB 라우팅은 변경하지 않았다.

## 페이지 구분

- `http://192.168.0.38:3104/`: NODELOG 홈. 실제 최근 글로 연결되는 HTML 카드 위에 장식용 WebGL 지식 코어를 렌더링한다.
- `http://192.168.0.38:3104/thivelab`: THIVELAB 브랜드 홈. 독립 레이아웃과 다섯 스크롤 장면을 사용한다. NODELOG·TOOLS·CIPHER·MOA는 실제 서비스로 연결하고 LABS·ENTERPRISE는 준비 중으로만 표시한다.
- DEV의 `/thivelab`은 `noindex, nofollow`를 출력한다. 운영의 `/thivelab`은 자기 canonical과 `index, follow`를 사용하며 사이트맵에 한국어 단일 URL을 포함한다. 기존 `/`의 NODELOG 콘텐츠와 글 URL은 이동하지 않았다.

## 구현과 접근성

- Three.js의 WebGL 2 장면을 사용한다. THIVELAB 모델은 스크롤 위치에 따라 카메라와 궤도가 변한다. NODELOG 모델은 히어로 안에서만 보인다.
- 글과 서비스 링크는 캔버스 밖의 HTML에 둔다. WebGL 초기화가 실패하면 CSS 대체 그래픽과 본문·링크가 남는다.
- 장면이 화면 밖에 있거나 탭이 숨겨지면 불필요한 렌더링을 줄인다. `prefers-reduced-motion`에서는 연속 애니메이션을 멈추고 스크롤 위치의 정지 장면을 그린다.
- 픽셀 비율을 최대 1.5로 제한한다. 사용자 파일·AI API·새 DB·광고 기능은 추가하지 않았다.
- 3D 코어의 재질·조명·궤도 마커를 밝게 조정하고, 챕터별 색과 탐색 HUD·진행 표시를 추가했다. 챕터의 읽기용 배경은 상하가 투명하게 사라지는 오버레이로 바꿔 스크롤 경계에 직선이 생기지 않게 했다.
- 레퍼런스의 스크롤 스토리텔링 개념을 서비스 구조에 맞게 해석했다. INTRO의 코어가 NODELOG의 문서 패널, TOOLS의 작업 모듈, EXPLORE의 두 포털과 교차하며 변한다. 오브젝트는 챕터 경계에서 서서히 나타나고 사라진다. 레퍼런스의 모델·에셋·코드는 복제하지 않았다.
- 참고한 공개 사이트: [Lusion](https://lusion.co/), [Active Theory](https://v5.activetheory.net/), [Bruno Simon](https://bruno-simon.com/). 직접 확인 범위는 아래에 구분했다.

## 레퍼런스 브라우저 확인

- 앱에 연결된 브라우저는 아직 없었다. 별도 로컬 Chromium에서 세 사이트를 열어 입력을 시도했다.
- Active Theory: 첫 화면의 WebGL 거리 장면이 휠 입력 후 달라지는 것을 확인했다. 중앙 진입 영역을 클릭하자 `/work`로 이동했고, 3D 장면 위에 프로젝트 이름과 목록 탐색 UI가 배치된 화면을 확인했다.
- Lusion: 응답은 200이고 캔버스 3개가 생성됐지만 로딩 화면에서 벗어나지 않았다. 비디오 자원과 Cloudflare 챌린지 요청 실패가 관찰됐으며, 메뉴와 본문 스크롤 결과는 확인하지 못했다.
- Bruno Simon: 응답은 200이고 캔버스 1개가 생성됐지만 로딩 장면에서 벗어나지 않았다. 키보드 입력에 대한 본문 변화는 확인하지 못했다.
- 이 확인 과정에서는 운영 코드와 DEV 디자인을 추가 변경하지 않았다. 세부 화면을 모두 검증한 것으로 해석하지 않는다.

## 검증

- 실행 중인 DEV 경로 `/`와 `/thivelab`에서 HTTP 200 확인.
- 소스 경로 밖의 격리 복사본에서 Next.js 프로덕션 빌드와 TypeScript 검사 통과.
- Chromium 데스크톱 1440×900, 모바일 에뮬레이션 390×844에서 두 페이지의 WebGL 초기화, 링크, 스크롤 장면, 가로 넘침을 확인. 일반 동작과 동작 줄이기 설정을 각각 검사.
- 개선 후 `/thivelab`의 데스크톱·모바일 첫 장면과 챕터 경계 전후 화면을 캡처해 확인했고, 브라우저 점검과 TypeScript 검사를 다시 통과했다.
- 서비스별 3D 형태를 추가한 뒤 Chromium 데스크톱·모바일의 일반 동작과 동작 줄이기 설정, 타입 검사, 격리 복사본의 프로덕션 빌드를 통과했다. 공유 재질과 기하학 객체로 장면 자원을 줄였다.
- 실제 iOS Safari·Android Chrome, 저사양 GPU, 배터리·프레임률은 아직 측정하지 않았다.

## 운영 반영 후 남은 검증

브랜드 홈은 `https://www.thivelab.com/thivelab`에 공개했다. 실제 iOS Safari·Android Chrome, 저사양 GPU의 성능과 발열은 추가 확인이 필요하다. 롤백 릴리스와 운영 검증 결과는 `THIVELAB_3D_PRODUCTION_PLAN.md`에 기록했다.
