# Brand architecture

THIVELAB is the parent studio. Its current public homepage remains at `/` and continues to surface NODELOG content.

| Product | Role | Current destination/state |
| --- | --- | --- |
| NODELOG by THIVELAB | Learn: technical media and engineer guides | Existing root, categories, articles and guides |
| CIPHER / VAULT | Compete: challenge experience | `https://game.thivelab.com/` current demo |
| LABS | Practice: hands-on labs | Preparing; no invented link |
| MOA | Create: AI creative workspace | `https://moa.thivelab.com/` |
| ENTERPRISE | Business: security, AI and private challenges | Preparing; no invented link |

Global navigation names the parent and available products. The existing NODELOG categories remain a separate local navigation. Search, language, theme and subscription controls remain available. Blog authentication does not exist, so Login/Profile is omitted.

Existing NODELOG metadata, article titles, publisher schema and URL identity remain as-is in this phase. Visible product copy can say `NODELOG by THIVELAB`. Do not claim live LABS/ENTERPRISE features or live CIPHER statistics.
