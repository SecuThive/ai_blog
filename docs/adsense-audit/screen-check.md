## 수정
1. 모바일 검색 결과 카드가 화면 밖으로 밀렸다(오른쪽 끝 478px). 원인은 `.split`의 `1fr` 열이 긴 영문 식별자 때문에 넓어진 것이다. `minmax(0, 1fr)`로 바꾸고, 카드 레이아웃을 CSS 클래스로 옮겨 640px 이하에서 썸네일 88px로 줄였다. 시리즈 화면의 "22편" 배지 잘림도 같은 원인이라 함께 고쳐졌다.
2. LABS/ENTERPRISE: 모바일 메뉴에서 CIPHER·MOA와 같은 색으로 보였다(`.mobile-nav-item` 색이 덮어씀). 흐리게 하고 "준비 중 · 아직 이용할 수 없음" 표시와 `aria-disabled`를 붙였다. 홈 카드는 점선 테두리와 "COMING SOON · 아직 이용할 수 없음"으로 바꿨다. 링크는 없다.
3. 홈 최신 글 필터: 최신 12편에 없는 카테고리 탭(예: IT)을 누르면 탭 줄까지 사라져 되돌아갈 수 없었다. 글이 있는 카테고리 탭만 보이게 하고 인프라·보안 탭을 추가했다. `aria-pressed`를 붙였다.
4. 모바일 목차: 960px 이하에서 사이드 목차가 숨겨져 목차가 없었다. 본문 앞에 접을 수 있는 목차(h2)를 추가했다.
5. 구독 완료 문구가 메일을 보내지 않았을 때도 "확인 메일을 보내드렸습니다"라고 했다. API가 `welcomeEmailSent`를 돌려주고, 보내지 않았으면 "구독이 등록되었습니다"로 안내한다.
6. 댓글 API가 DB 오류 원문(`error.message`)을 화면에 내보냈다. 서버 로그에만 남기고 일반 문구를 돌려준다.

## 확인하지 못한 것
- 실제 광고가 채워진 화면. localhost에서는 광고가 나오지 않고, 광고 요청도 막았다. 자동 광고가 댓글 폼이나 공유 버튼 옆에 붙는지는 승인 뒤 AdSense 미리보기로 확인하고, 필요하면 자동 광고 설정에서 해당 영역을 제외한다.
- 문의 페이지의 "평균 답변 36시간 이내"는 근거 자료를 찾지 못했다. 편집 체크리스트에 남긴다.
- 실제 Resend 발송.
